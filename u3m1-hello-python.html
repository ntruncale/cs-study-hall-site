A Jesuit and a machine

Context

In 1949, an Italian Jesuit priest named Fr. Roberto Busa, S.J. had a huge goal. He wanted to make an index of every word St. Thomas Aquinas ever wrote, about 11 million words. By hand, it would take more than a lifetime.

So he went to IBM in New York and asked for help. Using punched cards like the one shown here, and later early computers, his team built the Index Thomisticus over about 30 years. Many people call it the start of the digital humanities: using computers to study human culture.

Fr. Busa learned what every programmer learns. The machine does exactly what you tell it, no more and no less. That's where you start today.

Three ideas

Experience

Idea 1: A program is a list of instructions, run top to bottom

print( ) tells Python to show something on the screen. Python runs line 1, then line 2, and so on.

Code
print("Good morning!")
print("Welcome to study hall.")
Output
Good morning!
Welcome to study hall.

Idea 2: Text goes inside quotes

Text in quotes is called a string. The quotes tell Python "show these exact letters." Numbers don't need quotes.

Code
print("Room 214")
print(10 + 5)
Output
Room 214
15

Idea 3: Variables remember things

A variable is a labeled box that holds a value. The = sign puts a value in the box. After that, you can use the label anywhere.

To put a variable inside a sentence, use an f-string. Put an f right before the opening quote, and the variable's name in curly braces { }.

Code
name = "Maria"
year = 2030
print(f"Hi, {name}!")
print(f"You graduate in {year}.")
Output
Hi, Maria!
You graduate in 2030.
Errors are normal. Every programmer sees error messages every day. When you get one, read the message, look at the line number it gives, and check your quotes, parentheses, and spelling. In Python, print and Print are different words.
