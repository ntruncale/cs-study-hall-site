A loom, a countess and a loop

Context

In 1804, a French weaver named Joseph-Marie Jacquard built a loom controlled by a chain of punched cards. Each card told the loom which threads to lift. To repeat a pattern across a whole bolt of silk, the loom ran through the same cards again and again.

Decades later in England, Ada Lovelace studied Charles Babbage's design for a calculating machine called the Analytical Engine, which borrowed Jacquard's punched cards. In 1843 she published notes describing how the machine could calculate a complicated series of numbers. Her method repeated the same group of operations over and over, which is what we now call a loop. She wrote that the Engine "weaves algebraic patterns just as the Jacquard loom weaves flowers and leaves."

Many people call Lovelace the first computer programmer. The machine was never built in her lifetime, but her idea of repeating instructions is in almost every program written today.

Three ideas

Experience

Idea 1: for and range() repeat steps

A for loop repeats the indented lines under it. range(5) gives the numbers 0, 1, 2, 3, 4, so the loop runs 5 times. range(1, 6) starts at 1 and stops before 6: 1, 2, 3, 4, 5.

Code
for lap in range(1, 4):
    print(f"Lap {lap} done!")
print("Race finished.")
Output
Lap 1 done!
Lap 2 done!
Lap 3 done!
Race finished.

The last print isn't indented, so it runs once, after the loop is finished.

Idea 2: Loop through a list

A list holds several values in square brackets. A for loop can go through a list one item at a time.

Code
saints = ["Ignatius", "Francis Xavier", "Peter Faber"]
for saint in saints:
    print(f"St. {saint}, pray for us.")
Output
St. Ignatius, pray for us.
St. Francis Xavier, pray for us.
St. Peter Faber, pray for us.

Idea 3: Keep a running total

To add things up, start a variable at 0 before the loop, add to it inside the loop, and print it after the loop.

Code
hours = [3, 5, 2]
total = 0
for h in hours:
    total = total + h
print(f"Total service hours: {total}")
Output
Total service hours: 10
