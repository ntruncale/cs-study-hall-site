Amazing Grace

Context

Grace Hopper earned a Ph.D. in mathematics from Yale, joined the U.S. Navy during World War II, and became one of the first programmers of the Harvard Mark I computer. She later rose to the rank of rear admiral.

In the early 1950s, programmers wrote the same pieces of code again and again: code to calculate a square root, code to print a number. Hopper had an idea. Why not write each piece once, give it a name, store it in a library, and let a program called a compiler pull in the pieces automatically? In 1952 her team built one of the first compilers, called A-0.

Those named, reusable pieces of code are what we now call functions. Hopper went on to help create COBOL, a programming language that still runs many banks and government systems today.

Three ideas

Experience

Idea 1: def creates a function; calling it runs it

def gives a set of steps a name. The steps don't run until you call the function by writing its name with parentheses.

Code
def morning_prayer():
    print("Lord, be with us today.")
    print("Amen.")

morning_prayer()
morning_prayer()
Output
Lord, be with us today.
Amen.
Lord, be with us today.
Amen.

Idea 2: Parameters pass information in

A parameter is a variable in the parentheses of def. When you call the function, the value you put in the parentheses goes into that variable.

Code
def thank(name, hours):
    print(f"Thank you, {name}, for {hours} hours of service!")

thank("Ana", 12)
thank("Ben", 30)
Output
Thank you, Ana, for 12 hours of service!
Thank you, Ben, for 30 hours of service!

Idea 3: return sends an answer back

Some functions calculate an answer. return sends the answer back to the line that called the function, so you can store it, print it or use it in more math. print only shows something on the screen; return hands it back to your program.

Code
def area(width, length):
    return width * length

garden = area(4, 6)
print(f"The garden is {garden} square feet.")
print(f"Two gardens: {area(4, 6) * 2} square feet.")
Output
The garden is 24 square feet.
Two gardens: 48 square feet.
